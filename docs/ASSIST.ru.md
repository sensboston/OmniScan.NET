# Онлайн-сервисы: поворот фото и подписи к сканам

OmniScan полностью работает без интернета. С ключом API онлайн-сервиса ИИ она может ещё:

- **Переворачивать фото как надо.** Снимок, положенный на стекло боком или вверх ногами, после
  сохранения поворачивается правильно, даже если на нём нет текста, по которому видно, где верх.
- **Подписывать фото и PDF** короткой строкой с несколькими словами для поиска, например
  `Massachusetts ID card (Mass ID, driver's license, identity card)` или
  `Счёт за электричество, октябрь 2026 (электроэнергия, коммунальные услуги)`.

Оба режима выключены, пока вы не введёте ключ и не отметите их в **Настройки → ИИ**. Ключ проверяется,
как только вы его вставите; он хранится в `OmniScan.ini` в зашифрованном виде для вашей учётной записи
Windows (DPAPI), и ни другой пользователь, ни другой компьютер прочитать его не смогут.

## Куда попадают подписи

| | Фото (JPEG) | PDF | Другие изображения |
|---|---|---|---|
| `descript.ion` в папке (показывают и ищут Total Commander и Far Manager) | ✓ | ✓ | ✓ |
| Свойства файла: *Тема*, *Комментарии* (показывает Проводник, индексирует поиск Windows) | ✓ | — | — |
| Заголовок документа (программы просмотра PDF показывают его на вкладке или в заголовке окна) | — | ✓ | — |

Как найти скан: в Far Manager — поиск текста в папке `Scans` (`Alt+F7`, со включённым показом скрытых
файлов: `descript.ion` скрытый, как его делает Total Commander); в Проводнике — поиск находит фото по
комментариям. Имена файлов никогда не меняются.

Подписи пишутся на языке программы и никогда не содержат номеров счетов, карт и документов, адресов,
телефонов и дат рождения: они лежат обычным текстом рядом с файлом.

## Что отправляется, а что нет

| Для чего | Что уходит с вашего компьютера |
|---|---|
| Поворот фото | 4 маленькие копии фото (384 пикселя по длинной стороне), повёрнутые 4 способами; если ответ «повернуть», то ещё раз в другом порядке, для проверки |
| Подпись к фото | одна маленькая копия (384 пикселя), в том же запросе |
| Подпись к PDF | его первая страница, 1280 пикселей по длинной стороне |

Больше ничего не отправляется: ни остальные страницы PDF, ни сканы в полном размере, ни имена файлов,
ни что-либо о вашем компьютере. Страницы PDF сервис никогда не поворачивает: их выравнивает ваш
компьютер, распознаванием текста, встроенным в Windows.

**Подумайте, прежде чем включать «Подписывать фотографии и PDF»,** если сканируете бумаги, которые не
должны видеть посторонние: первая страница каждого PDF уходит в выбранный вами сервис.

## Сервисы

Сервис определяется по ключу. Проверено в ноябре 2026 года:

| Сервис | Ключ начинается с | Выбранная модель | Примечания |
|---|---|---|---|
| [OpenAI](https://platform.openai.com/api-keys) | `sk-` | `gpt-6-luna` | Доли цента за фото; 2–10 с на фото. Чаще оставляет трудные фото как были (см. ниже). |
| [Google AI Studio](https://aistudio.google.com/apikey) | `AIza…` или `AQ.` | `gemini-3.5-flash-lite` | **Самая точная в наших проверках**, и есть бесплатный тариф (см. замечание о приватности ниже). 1–8 с на фото. |
| [DeepSeek](https://platform.deepseek.com/api_keys) | `sk-` (32 шестнадцатеричные цифры) | `deepseek-flash` | Точные подписи; в наших проверках один раз повернула фото неправильно. |
| Anthropic, xAI, OpenRouter | `sk-ant-`, `xai-`, `sk-or-` | выбирается из списка моделей ключа | Поддерживаются, пока не проверены. |

Как проверенные модели справились с нашим набором сканов: 24 повёрнутых фото и два трудных случая, где
почти ничто не показывает, где верх, — космический аппарат, лежащий на боку, на котором видна только
перевёрнутая надпись, и музейный снимок космической капсулы, сделанный снизу (каждый спрашивали
несколько раз):

| Модель | Фото повёрнуто верно (из 24) | Трудный случай 1 (из 4) | Трудный случай 2 (из 16) |
|---|---|---|---|
| gemini-3.5-flash-lite | 24 | 4 | 16 |
| deepseek-flash | 23 | 0–2, один раз неверный поворот | — |
| gpt-6-luna | 23 | 1 (в остальных «не уверена») | 12 (3 «не уверена», 1 неверно) |
| gpt-6.1-terra | 24 | 4 | — |

«Не уверена» оставляет фото как было; его всегда можно повернуть кнопками под миниатюрой.
**Для поворота фото лучший выбор — Gemini**, если вас устраивают условия её бесплатного тарифа (см. ниже).

Фото поворачивается, только если совпадают два ответа с копиями в разном порядке; иначе оно остаётся
как было. Наклейки (вырезанные по контуру) не отправляются никогда: они сохраняются так, как лежат.

### Приватность: что каждый сервис может делать с отправленным

Это зависит от сервиса и вашего тарифа, а их условия меняются; прочитайте их, прежде чем выбирать.
Вкратце, на момент написания:

- **OpenAI (платный API):** данные, отправленные через API, по умолчанию не используются для обучения
  их моделей; они могут храниться ограниченное время для проверки на злоупотребления.
- **Google AI Studio, бесплатный тариф:** отправленное **может использоваться для улучшения продуктов
  Google, и его могут просматривать люди.** Для открыток и фото из отпуска это нормально; для документов
  и фото людей стоит подумать дважды. Платный тариф так ваши данные не использует.
- **DeepSeek:** сервис работает из Китая, по китайским законам, и его политика конфиденциальности
  разрешает использовать отправленное для улучшения сервиса. Мы бы не отправляли туда личные документы.
- **OpenRouter** передаёт запросы моделям других компаний, на их условиях.

Краткую версию этого OmniScan показывает в **Настройки → ИИ** для сервиса введённого ключа.

## Выбор модели вручную

Модель выбирается под сервис вашего ключа. Чтобы использовать другую, укажите её в `OmniScan.ini`
(рядом с `OmniScan.exe`):

```ini
[Assist]
; Model: the model to use first; empty = chosen by the program for the key's service.
Model = gpt-6.1-terra
```

В файле перечислены проверенные модели и есть закомментированная строка для `gpt-6.1-terra`: она
правильно поворачивает больше фото, чем `gpt-6-luna` (в том числе те, где верх виден только по надписи),
примерно в десять раз дороже.

Когда модель занята (обычное дело для новых моделей на бесплатных тарифах), запрос уходит следующей
модели сервиса, а занятая не трогается две минуты; модель, ставшая недоступной для вашего ключа,
пропускается на полчаса.
