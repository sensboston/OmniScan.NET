First release.

**Download `OmniScan.exe` below** — a single portable file, nothing to install, no .NET needed.
Put it in any folder you like and run it; settings are kept in `OmniScan.ini` next to it.

The executable is not code-signed yet, so on first start Windows SmartScreen may say
"Windows protected your PC": click **More info** → **Run anyway**.

Requires Windows 10 or 11 (64-bit).
