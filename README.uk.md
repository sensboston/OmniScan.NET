Невелика й швидка програма для планшетних сканерів під Windows: документи, фото, багатосторінкові PDF,
наліпки — і USB-сканер, доступний з усіх комп’ютерів домашньої мережі.

**[Завантажити OmniScan.exe](https://github.com/sensboston/OmniScan.NET/releases/latest/download/OmniScan.exe)**
(~68 МБ) — один переносний файл: нічого не треба встановлювати, .NET теж не потрібен. Windows 10 (1809+) або 11, 64 біт.

Уже встановлено [.NET 10 Desktop Runtime](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe)? Тоді
**[полегшена версія](https://github.com/sensboston/OmniScan.NET/releases/latest/download/OmniScan-lite.exe)**
(~10 МБ) — та сама програма, лише без середовища виконання всередині.

## Чим вона відрізняється

- **Один USB-сканер на весь дім.** Увімкніть спільний доступ на комп’ютері, до якого під’єднано сканер, і
  OmniScan на всіх інших комп’ютерах покаже його як свій — без драйверів, налаштувань і облікових
  записів. Поки хтось сканує за тим комп’ютером, скан з іншого одразу отримує відмову (він ніколи не
  забере те, що лежить на склі), у списку сканерів світиться зелене або червоне коло, а інший комп’ютер
  може однією кнопкою попросити звільнити сканер.
- **Наліпки, вирізані по контуру.** Покладіть на скло наліпки, і OmniScan виріже кожну за її формою з
  акуратною білою облямівкою на прозорому тлі (PNG). Наліпки програма помічає сама й пропонує цей режим,
  а попередній перегляд показує їхні контури. Фото й листівки в тому самому скані лишаються
  прямокутними.
- **Скани, які потім можна знайти.** З вашим власним ключем API (OpenAI, Google AI Studio або DeepSeek)
  фото повертаються як слід, а кожне фото й PDF отримують короткий підпис зі словами для пошуку —
  `Massachusetts ID card (Mass ID, driver's license)`, `Рахунок за електрику, жовтень`. Підпис
  записується туди, де його шукають ваші інструменти: у `descript.ion` (Total Commander, Far), у
  властивості фото (Провідник, пошук Windows) і в заголовок PDF. Вимкнено, доки ви самі не ввімкнете;
  що надсилається і що кожен сервіс може з цим робити — на сторінці [Online services](docs/ASSIST.md)
  (англійською).
- **Кольоровий папір стає білим** — як на копірці: аркуш, надрукований на жовтому папері, виходить на
  білому, а друк і його сірі плашки зберігаються.
- **Програма сама розбирає, що лежить на склі.** Кілька фото, покладених як завгодно — навскіс, впритул,
  з білим небом, що зливається з кришкою, — стають окремими вирівняними файлами. Аркуш із текстом,
  збережений як зображення, пропонує стати PDF без повторного сканування.

## Можливості

- **Одне вікно, миттєвий запуск.** Сканери шукаються у фоні, вікно їх ніколи не чекає.
- **Фото:** знаходяться, обрізаються, вирівнюються й зберігаються по одному у файл. Рамки показуються в
  попередньому перегляді, їх можна пересувати, змінювати розмір, повертати, додавати й видаляти до
  сканування.
- **Документи:** поля прибираються, перекіс і орієнтація сторінки (0/90/180/270) виправляються — навіть
  коли верх можна зрозуміти, лише прочитавши сторінку: для цього використовується розпізнавання тексту,
  вбудоване у Windows, просто на вашому комп’ютері.
- **Багатосторінковий PDF:** після кожної сторінки картка підказує, що далі («Покладіть наступну сторінку
  на скло — її буде відскановано через 15 с»). Будь-яку сторінку можна перезняти або видалити, сторінки
  можна вставляти, порожні пропускаються; той самий аркуш, відсканований двічі, помічається; до
  останнього збереженого PDF можна пізніше додати сторінки.
- **Теки за днями й безпечні імена:** `Scans\2026-11-24\scan_001.jpg`, один лічильник для всіх форматів;
  наявні файли ніколи не перезаписуються.
- **Смуга результатів і перегляд:** кожен збережений файл можна повернути, видалити або відкрити одразу
  після скану; клацання показує його на все вікно, з масштабуванням.
- **Оновлюється сама:** раз на день OmniScan перевіряє, чи немає нової версії на GitHub, і пропонує її
  встановити: завантажує, перевіряє й перезапускається сама. Можна вимкнути.
- **Переносна:** налаштування — у звичайному файлі `OmniScan.ini` поруч із програмою (або в
  `%AppData%\OmniScan`, якщо в цю теку не можна писати). Нічого не встановлюється, нічого не лишається.
- **29 мов інтерфейсу**, світла й темна тема.

## Перший запуск

Програма поки що не підписана цифровим підписом, тому Windows SmartScreen може показати «Windows захистила
ваш ПК». Натисніть **Докладніше** → **Усе одно запустити**. (Див. розділ [Підтримка](#підтримка) нижче.)

Коли ввімкнено спільний доступ до сканера, Windows один раз запитає, чи дозволити OmniScan працювати в
мережі: дозвольте для приватних мереж. Сервер відповідає лише комп’ютерам локальної мережі.

## Як це працює

- Сканування йде через **WIA 2.0**, тож підходить будь-який сканер із драйвером для Windows.
- Обробка зображень — повністю керований код, у пам’яті, на основі
  [Leptonica.Managed](https://github.com/sensboston/Leptonica.Managed).
- Спільний доступ: UDP-розсилка для пошуку й звичайний HTTP для сканів (необроблені кадри без втрат,
  gzip); обробка завжди відбувається на тому комп’ютері, за яким ви сидите.

Нотатки про внутрішню будову: [docs/DESIGN.md](docs/DESIGN.md) (англійською).

## Збирання з вихідного коду

Потрібен .NET 10 SDK під Windows.

```powershell
dotnet build OmniScan.Net.slnx -c Release
dotnet test tests/OmniScan.Net.Tests -c Release

# Один переносний OmniScan.exe (середовище виконання всередині):
dotnet publish src/OmniScan.Net.App -c Release -r win-x64 -o publish

# Полегшений OmniScan.exe (використовує встановлений .NET 10 Desktop Runtime):
dotnet publish src/OmniScan.Net.App -c Release -r win-x64 -p:Lite=true -o publish-lite
```
