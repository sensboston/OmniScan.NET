Небольшая и быстрая программа для планшетных сканеров под Windows: документы, фото, многостраничные PDF,
наклейки — и USB-сканер, доступный со всех компьютеров домашней сети.

**[Скачать OmniScan.exe](https://github.com/sensboston/OmniScan.NET/releases/latest/download/OmniScan.exe)**
(~68 МБ) — один переносимый файл: ничего не нужно устанавливать, .NET тоже не нужен. Windows 10 (1809+) или 11, 64 бит.

Уже установлен [.NET 10 Desktop Runtime](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe)? Тогда
**[облегчённая версия](https://github.com/sensboston/OmniScan.NET/releases/latest/download/OmniScan-lite.exe)**
(~10 МБ) — та же программа, только без среды выполнения внутри.

## Чем она отличается

- **Один USB-сканер на весь дом.** Включите общий доступ на компьютере, к которому подключён сканер, и
  OmniScan на всех остальных компьютерах покажет его как свой — без драйверов, настройки и учётных
  записей. Пока кто-то сканирует за тем компьютером, скан с другого сразу получает отказ (он никогда не
  заберёт то, что лежит на стекле), в списке сканеров горит зелёный или красный кружок, а другой
  компьютер может одной кнопкой попросить освободить сканер.
- **Наклейки, вырезанные по контуру.** Положите на стекло наклейки, и OmniScan вырежет каждую по её
  форме с аккуратной белой окантовкой на прозрачном фоне (PNG). Наклейки программа замечает сама и
  предлагает этот режим, а превью показывает их контуры. Фото и открытки в том же скане остаются
  прямоугольными.
- **Сканы, которые потом можно найти.** С вашим собственным ключом API (OpenAI, Google AI Studio или
  DeepSeek) фото переворачиваются как надо, а каждое фото и PDF получают короткую подпись со словами для
  поиска — `Massachusetts ID card (Mass ID, driver's license)`, `Счёт за электричество, октябрь`.
  Подпись записывается туда, где её ищут ваши инструменты: в `descript.ion` (Total Commander, Far), в
  свойства фото (Проводник, поиск Windows) и в заголовок PDF. Выключено, пока вы сами не включите; что
  отправляется и что каждый сервис может с этим делать — на странице
  [Онлайн-сервисы](docs/ASSIST.ru.md).
- **Цветная бумага становится белой** — как на копире: лист, напечатанный на жёлтой бумаге, выходит на
  белой, а печать и её серые плашки сохраняются.
- **Программа сама разбирает, что лежит на стекле.** Несколько фото, положенных как попало — наискосок,
  вплотную, с белым небом, сливающимся с крышкой, — становятся отдельными выровненными файлами. Лист с
  текстом, сохранённый картинкой, предлагает стать PDF без повторного сканирования.

## Возможности

- **Одно окно, мгновенный запуск.** Сканеры ищутся в фоне, окно их никогда не ждёт.
- **Фото:** находятся, обрезаются, выравниваются и сохраняются по одному в файл. Рамки показываются в
  превью, их можно двигать, менять размер, поворачивать, добавлять и удалять до сканирования.
- **Документы:** поля убираются, перекос и ориентация страницы (0/90/180/270) исправляются — даже когда
  верх можно понять, только прочитав страницу: для этого используется распознавание текста, встроенное
  в Windows, прямо на вашем компьютере.
- **Многостраничный PDF:** после каждой страницы карточка подсказывает, что дальше («Положите следующую
  страницу на стекло — она отсканируется через 15 с»). Любую страницу можно переснять или удалить,
  страницы можно вставлять, пустые пропускаются; один и тот же лист, отсканированный дважды, замечается;
  к последнему сохранённому PDF можно позже добавить страницы.
- **Папки по дням и безопасные имена:** `Scans\2026-11-24\scan_001.jpg`, один счётчик для всех форматов;
  существующие файлы никогда не перезаписываются.
- **Полоса результатов и просмотр:** каждый сохранённый файл можно повернуть, удалить или открыть сразу
  после скана; щелчок показывает его на всё окно, с масштабированием.
- **Обновляется сама:** раз в день OmniScan проверяет, нет ли новой версии на GitHub, и предлагает её
  установить: скачивает, проверяет и перезапускается сама. Можно отключить.
- **Переносимая:** настройки — в обычном файле `OmniScan.ini` рядом с программой (или в
  `%AppData%\OmniScan`, если в эту папку нельзя писать). Ничего не устанавливается, ничего не остаётся.
- **29 языков интерфейса**, светлая и тёмная тема.

## Первый запуск

Программа пока не подписана цифровой подписью, поэтому Windows SmartScreen может показать «Система Windows
защитила ваш компьютер». Нажмите **Подробнее** → **Выполнить в любом случае**. (См. раздел
[Поддержка](#поддержка) ниже.)

При включённом общем доступе к сканеру Windows один раз спросит, разрешить ли OmniScan работать в сети:
разрешите для частных сетей. Сервер отвечает только компьютерам локальной сети.

## Как это работает

- Сканирование идёт через **WIA 2.0**, поэтому подходит любой сканер с драйвером для Windows.
- Обработка изображений — полностью управляемый код, в памяти, на основе
  [Leptonica.Managed](https://github.com/sensboston/Leptonica.Managed).
- Общий доступ: UDP-широковещание для поиска и обычный HTTP для сканов (необработанные кадры без потерь,
  gzip); обработка всегда идёт на том компьютере, за которым вы сидите.

Заметки о внутреннем устройстве: [docs/DESIGN.md](docs/DESIGN.md) (на английском).

## Сборка из исходников

Нужен .NET 10 SDK под Windows.

```powershell
dotnet build OmniScan.Net.slnx -c Release
dotnet test tests/OmniScan.Net.Tests -c Release

# Один переносимый OmniScan.exe (среда выполнения внутри):
dotnet publish src/OmniScan.Net.App -c Release -r win-x64 -o publish

# Облегчённый OmniScan.exe (использует установленный .NET 10 Desktop Runtime):
dotnet publish src/OmniScan.Net.App -c Release -r win-x64 -p:Lite=true -o publish-lite
```
